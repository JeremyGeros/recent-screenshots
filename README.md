# recent-screenshots

Shows the screenshots you took in the last 2 minutes as thumbnails above the prompt box in the Claude desktop app. Click a thumbnail to add it to your next message (it gets an orange border); click again to remove it. When you send, Claude reads the added screenshots, and they appear under your message.

macOS only. It watches your screenshot folder (the one set in the Screenshot app's Options, Desktop by default).

## Install

At the prompt of a terminal Claude Code session:

```
/plugin install recent-screenshots --marketplace JeremyGeros/recent-screenshots
```

From a shell:

```bash
claude plugin install recent-screenshots --marketplace JeremyGeros/recent-screenshots
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `JeremyGeros/recent-screenshots`, then Add plugin.
